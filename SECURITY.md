# Security Policy

Huallet holds users' keys, so security reports are our top priority.

## Reporting a vulnerability

**Do not open a public issue.** Report privately through GitHub:
*Security* tab → *Report a vulnerability* on [ChihuahuaChain/huallet](https://github.com/ChihuahuaChain/huallet/security).

Please include the affected version, steps to reproduce and the impact you expect. We will acknowledge the report,
keep you informed while we work on a fix, and credit you in the release notes if you wish.

## Scope

In scope: the Huallet extension, the Huallet web app, the build scripts and anything that could lead to loss of funds,
disclosure of keys or recovery phrases, unauthorized signatures, or bypass of the approval flow.

Out of scope: vulnerabilities in third-party wallets, blockchain nodes or websites that Huallet connects to.

## Supported versions

Only the latest released version receives security fixes.
